# Chanindi Ranasinghe — Portfolio

A responsive static portfolio built with HTML and CSS. `index.html` contains the published site, and `me.jpg.png` is the portrait image.

## Update the portfolio

1. Serve this folder on your hosting provider, or start a local web server in this folder (for example, `python -m http.server 8000`) and open `http://localhost:8000/admin.html`.
2. Choose **Edit page** and click text in the preview to change it. Choose **Finish editing** when you are done.
3. Choose **Download updated site**. Replace the existing `index.html` with the downloaded file, then publish your site as usual.

The admin editor works in the browser and exports a static HTML file. It has no login or server-side storage; publish the downloaded file for changes to appear for everyone. Keep `styles.css` and `me.jpg.png` next to `index.html` when publishing.

## Included sections

About, education, technical and professional skills, HR experience, volunteering, design portfolio links, projects, and contact information.
